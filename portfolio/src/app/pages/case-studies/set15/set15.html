Overview

This case study covers a redesign of the core BoxBox Bootcamp platform. The redesign focuses on re-aligning elements of the website with the set theme without sacrificing text readability and introduces new quality of life features to increase website usability.

CONTEXT

What is the BoxBox Bootcamp?

Bootcamp is a Riot Games-funded event run by Twitch streamer, BoxBox. It is a competition where streamers and community members try to climb the in-game ranked ladder as quickly as they can before they get eliminated from the event. Bootcamp happens at the start of every set and happens about three times a year.

Why is the Bootcamp website important?

The Bootcamp website is where participants can track how they are doing in the event. It is Bootcamp’s most critical platform as it handles eliminations and shows participant rankings in real time. It also serves as an information hub for participants and viewers alike.

THE PROBLEM

Why a redesign?

I decided to redesign the website after using it to sign up for the community leaderboard. I found it hard on the eyes (white text on bright-colored backgrounds) and difficult to navigate - I wanted to challenge myself to come up with a more streamlined design while working with brighter colors than I am used to.

What needed to change?

I identified three areas in which I believed the website could be improved, as well as an addition that I wanted to create.

01

Font Color + Readability

The website features white text overlaid on very bright colors. These neon colors are part of the overall set theme and design, so they can’t be swapped out.

02

Theming

Aside from the set logo on two pages, the website is text-heavy. Set-related graphics can be added to help differentiate between positions and add polish to the design.

03

Non-optimized Elements

Some elements in the design could be updated to make better use of common UI practices that exist both inside and outside of gaming spaces.

04

Quality of Life Tools (new addition)

The website was missing quality-of-life (QOL) tools that could improve user navigation. In particular, I noticed that it was annoying to scroll through the leaderboard pages to see who was close to elimination, as well as who was actively streaming at the moment.

MY SOLUTION

What did I change?

01

Font Color + Bounding Boxes + Color Contrast

Changed font color from white to dark purple and added bounding boxes to large amounts of text to increase readability (cleaner color contrast).

Switched to darker background gradients to decrease eye strain and added a grain texture to further decrease attention drawn by the colors.

02

More Obvious Theming

Added in-game sprites and emotes as assets to different pages - these help break up the walls of text into more digestible sections.

Swapped out fonts for typefaces that fit better with the overall set theme (cyber/fighting-game aesthetic) without sacrificing readability.

03

Updated Elements and Layouts

Updated “danger” indication to a broken, blinking heart - draws upon a common UI element found in older video games.

Transformed the “live” indicator into a red dot on the streaming platform icon - relies on positive transfer effect related to unread notifications on mobile devices.

04

Zone Indicators + Floating Navigation Bar + “Live” Toggle

Added zone indicators (danger zone, eliminated) and created a floating navigation bar with buttons to quickly jump to the indicators.

Added a “live” toggle to the floating navigation bar - toggles a focused view to easily distinguish between streamers that are currently live and offline.

LEARNINGS

What did I learn from working on this project?

01

A first idea is a starting point, not the final draft - make it first and improve it later.

I’ve struggled in the past with the notion of “doing things right or not doing them at all”. This is the first personal project I’ve been able to complete (with pride) since graduating. Strangely enough, I started this project as “just practice” - this change of mindset helped me let go of chasing the idea of the “perfect design”. I could make as many mistakes as I needed to and in doing so, I was able to create a design that has been officially adopted for use by the event that I continue to iterate on.

02

Breaks are necessary to recharge - you’ll return with a different perspective and more clarity.

This project took about 4 months to complete due to a plethora of reasons but the biggest roadblock occurred in late November. I was stuck on how to design a QOL tool to make navigating the leaderboard easier. Everything I designed was either too complicated or could easily be replaced by using native browser searching (Ctrl/Cmd + F). I took a break for the month of December and almost gave up on this project. When I reopened the file in January to try one last time, I was finally able to create the floating navigation bar tool for the leaderboards.
